# vch36 · ОБТ «36» — Александровск · рассвет

Танковый симулятор на three.js + cannon-es. Раньше всё жило в одном HTML-файле
на 22 МБ (вендорный бандл, код, HDRI, модели, звук). Здесь тот же самый проект,
разложенный по файлам: править код можно, не пролистывая 9-мегабайтную строку
с base64.

Сборка **50** — из монолита `vch36.single.aleksandrovsk.sunrise.html`:
код разнесён по модулям, большие данные вынесены в `data/`, плюс поправлены
туман и пересвет брони (см. [CHANGELOG.md](CHANGELOG.md)).

---

## Запуск

Вариант 1 — просто открыть `index.html` двойным щелчком. Все скрипты
классические (`<script defer>`), а не ES-модули, поэтому `file://` работает
без сервера и без сети.

Вариант 2 — любой статический сервер (нужен, если хотите Service Worker
и офлайн-кэш):

```bash
cd vch36
python3 -m http.server 8080
# → http://localhost:8080/
```

Локация выбирается параметром: `index.html?map=aleksandrovsk` (по умолчанию
стоит она же), `?map=map01`, `?map=sandbox`, `?map=polygon`, `?map=space`.

## Управление

| клавиша | действие |
|---|---|
| `W` `A` `S` `D` | движение |
| мышь | обзор / наведение |
| `ЛКМ` / `Space` | выстрел |
| `Shift` | ускорение |
| `C` | смена камеры |
| `Esc` | пауза / меню |
| `P` | стрельбище |
| `K` | трасса · `B` | бой |
| `L` | окраска (янтарь / хаки) |
| `Tab` | переключение танка (ОБТ «36» / Scorpion) |
| **`F`** | **панель «туман / свет»** |

### Почему classic-скрипты, а не ES-модули

Потому что общая область видимости: файлы переставляют друг другу короткие
внутренние имена из вендорного бандла (`fe`, `P`, `Lt`, `w` — это
`MeshStandardMaterial`, `Vector3`, `Mesh`, `Vec3`) и общие константы.
Объявления верхнего уровня в классических скриптах попадают в общую
лексическую область, поэтому всё работает как в исходном монолите — и при этом
сохраняется запуск с `file://` (ES-модули оттуда браузер не грузит).

**Порядок тегов в `index.html` обязателен.** Буквы 06a/06b/06c/06d/06e —
авторские; загружаются они в порядке `06a → 06c → 06b → 06e → 06d`.

## Панель «туман / свет» (клавиша F)

Правит картинку на ходу, без перезапуска сцены. Значения запоминаются
в `localStorage` (ключ `vch36.tune.v1`).

Вкладка **ТУМАН**: дымка вдаль, приземный туман, высота его слоя, свечение
у солнца, подсветка горизонта, плотность `FogExp2`.

Вкладка **СВЕТ**: экспозиция, окружение (IBL), солнце, hemi, fill, блеск брони
(множитель к `envMapIntensity` материалов танка), «мягкий ACES» (второй
тонмаппинг в пост-обработке), контраст.

То же самое из консоли:

```js
__vchTune.get()                              // текущие значения
__vchTune.set({mist: 0.008, envGain: 1.0})   // подстройка
__vchTune.reset()                            // к значениям из файла
__vchTune.fogOff()                           // выключить туман
```

Прочие точки входа: `__vchNight` (рассвет: `cfg`, `fog`, `tune()`),
`__vchLook` (окружение, износ, ливреи), `__vchUI` (меню, режимы),
`__vchLivery`, `__vchCacheReset()` (сброс кэша Service Worker).

## Сборка одного файла

```bash
python3 tools/build-single.py            # → dist/vch36.single.html
python3 tools/build-single.py out.html   # свой путь
```

Скрипт берёт порядок файлов из `index.html`, поэтому сборка всегда совпадает
с развёрнутой версией. Результат проверен: кадр в кадр совпадает
с развёрнутым репозиторием.

## Данные и автогенерация

Всё, что лежит в `data/` и `js/06a-*`, `js/06c-*`, — выжимки из исходных
ассетов (`tools/inline_map.py`, `tools/make_sky.py` в авторском проекте).
Самих генераторов в этом репозитории нет: файлы перенесены как есть.
Правки в них нужно вносить в генератор, иначе они затрутся.

При обновлении файлов не забудьте поднять версию кэша в `sw.js`
(`const CACHE = "vch36-v2"`), иначе браузер продолжит отдавать старую копию.


Если захотите играть прямо с GitHub: Settings → Pages → Deploy from branch →
`main` / root. Получится `https://Redtl.github.io/vch36/` (для приватного
репозитория Pages нужен платный план; иначе переключите репозиторий
в публичный).

кода, а самый большой файл (8.9 МБ) далёк от limits GitHub (100 МБ),
поэтому Git LFS не нужен.
